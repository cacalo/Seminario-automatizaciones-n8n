# Seminario de Automatización — Clase 1

Presentación en [Slidev](https://sli.dev) para la Unidad 1: *Introducción a la
automatización. Herramientas y primeros flujos.*

## Correr la presentación

```bash
npm install
npm run dev
```

Abre en `http://localhost:3030`.

## Atajos útiles en clase

| Tecla | Acción |
| --- | --- |
| `f` | Pantalla completa |
| `o` | Vista general de todas las diapositivas |
| `d` | Alternar modo oscuro |
| `g` | Ir a una diapositiva por número |

El **modo presentador** está en `http://localhost:3030/presenter`. Ahí se ven las
notas de cada diapositiva, que incluyen indicaciones de dictado y los momentos
previstos de participación del aula.

## Exportar

```bash
npm run export              # PDF
npm run export -- --format png
```

## Archivos

- `slides.md` — el contenido de la presentación
- `style.css` — paleta y tipografía; Slidev lo carga solo
